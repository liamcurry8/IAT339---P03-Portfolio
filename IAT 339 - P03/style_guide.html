Interactive Elements

In-text link

Rendered Element:

Click this to go to Google.

CSS selector:

.text-link

Sample code:

<p class="text-link">Click <a href="https://www.google.com/" target="_blank">this</a> to go to Google.</p>

Navigation Link

Rendered Element:

Default Button

CSS selector:

.button-input

Sample code:

<a href="https://www.google.com/" class="button-input">Default Button</a>

Submit/Reset Buttons

Rendered Element:

CSS Selector:

.submit-button

.reset-button

Sample code:

<input type="submit" class="submit-button" name="submit_button" value="Submit">
<input type="reset" class="reset-button" name="reset_button" value="Reset">

Text Input Field with Label

Rendered Element:

CSS Selector:

.form-input

Sample code:

<label>Text Input Field: </label>
<input type="text" class="form-input" placeholder="Type here:">

Radio Button with Label

Rendered Element:

CSS Selector:

.radio-button

Sample code:

<div class="button-input">
<input type="radio" class="radio-button" id="radio_button1" name="radio_button">
<label for="radio_button1">Radio Button 1</label>
<input type="radio" class="radio-button" id="radio_button2" name="radio_button">
<label for="radio_button2">Radio Button 1</label>
<input type="radio" class="radio-button" id="radio_button3" name="radio_button">
<label for="radio_button3">Radio Button 1</label>
</div>

Rendered Element:

Bio Template

Bio

I’m a third-year student in SFU’s School of Interactive Arts and Technology(SIAT) Program, with a focus in extended reality(XR) and game design. I’m inspired by the mystery and depth in the interactive experiences I grew up with, and through the knowledge from this program, I want to recreate those feelings with works of my own. A mixed-media workflow of digital and creative skills gives me what I need to translate any of my ideas into a realised environment or story. I have proficiencies in Blender/Maya, JS/Python, Adobe Premiere, and additional skills in sound design/music composition to help make my experiences more immersive and evocative.
